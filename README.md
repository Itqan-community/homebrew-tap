# Itqan Homebrew tap

Homebrew formulae for [Itqan](https://github.com/Itqan-community) tools.

## itqan

[`itqan`](https://github.com/Itqan-community/itqan-cli) installs and pins Itqan Quranic assets in
your project. On macOS (Apple Silicon or Intel) and Linux:

```bash
brew install itqan-community/tap/itqan
brew upgrade itqan
```

The formula installs the standalone binary from the
[GitHub Release](https://github.com/Itqan-community/itqan-cli/releases), so Python isn't needed.

`Formula/itqan.rb` is generated by itqan-cli's release workflow on each release, so don't edit it
by hand: change
[`scripts/homebrew_formula.py`](https://github.com/Itqan-community/itqan-cli/blob/main/scripts/homebrew_formula.py)
instead.
